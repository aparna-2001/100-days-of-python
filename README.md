# 100 Days of Python

My solutions and projects for the **100 Days of Code: The Complete Python Pro Bootcamp** on Udemy, taught by Angela Yu. Each day comes with a new mini-project, building from Python basics up through OOP, GUIs, web scraping, APIs, web development, and more.

## About the Challenge

The 100 Days of Code challenge involves writing code every day for 100 days and building a real project to reinforce each concept. This repo tracks my progress, one folder per day.

## Structure

```
100-days-of-python/

├── Day02/

├── Day03/

...
```

Each folder contains the code for that day's project, along with any supporting files (images, assets, etc.) it needs.
